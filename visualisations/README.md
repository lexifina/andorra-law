# El dret andorrà en 20 gràfics

**Català** · [English](README.en.md)

Gràfics del dret de tots els països, a partir de tot global-law: [global-law visualisations/](https://github.com/lexifina/global-law/tree/main/visualisations). Aquí, només els d’Andorra.

Vint gràfics del dret andorrà dibuixats només amb les dades d’aquest repositori: la Constitució del 1993 i els 1.040 textos del Consell General que el Butlletí Oficial del Principat d’Andorra (BOPA) publica com a lleis des del 1989, cadascun tal com es va aprovar (`lleis/`, `constitucio/`, `laws.csv`); l’historial de git, amb un commit per llei datat el dia que va entrar en vigor; les signatures i els preàmbuls de cada llei; i els 4.048 canvis que declaren les lleis posteriors (`data/amendments.csv`).

Obriu [`el-dret-andorra-en-20-grafics.html`](el-dret-andorra-en-20-grafics.html) en un navegador. La pàgina és un sol fitxer amb totes les dades a dins; del web només carrega la biblioteca d3 i les fonts. Els botons de dalt a la dreta canvien la llengua (català o anglès) i el tema (clar o fosc). Cada gràfic indica on són les seves dades al repositori, quants registres té i els seus límits, i té a sota una taula amb tots els números. Passant el ratolí per sobre d’una marca es veuen els valors exactes.

Els gràfics són descriptius: mostren el que conté el registre, no les causes.

## Límits

- **Cada llei tal com es va aprovar.** El BOPA no publica versions consolidades i el repositori no hi aplica les modificacions. Els gràfics de canvis (13 a 16) compten els que declaren les lleis posteriors a `data/amendments.csv`, una extracció automàtica que no és completa ni s’ha revisat a mà (abans del 2004 en troba pocs).
- **Només les lleis del Consell General.** No hi ha els decrets ni els reglaments del Govern, ni les ordinacions dels comuns.
- **Les categories surten dels títols** amb les regles de `src/prep.py`: el tipus de llei, si és qualificada (quan el títol ho diu), la matèria, l’impost i el codi; el que cap regla no reconeix compta com a «altres». 14 textos del tema «Lleis» del BOPA són edictes, quadres de pressupost i decrets d’esmena i no compten com a lleis.
- **Les dates d’aprovació** són les de la cita de cada llei o, si no en té, les de la signatura del síndic. Dues lleis del 1993 estan datades un dia després del butlletí que les publica i queden fora del gràfic 9. El preàmbul i la signatura de la Llei 2/2025, del 23 de gener, diuen «2024»; s’usa la data de la cita.
- **Les signatures** es llegeixen del text de cada llei. Abans del 3 de maig de 1993 les lleis les promulgaven els delegats permanents dels coprínceps o els veguers, o porten només la signatura del síndic.
- **Les mencions** (la Unió Europea i altres organismes, les monedes, els articles de la Constitució) es compten en el text: una llei compta si hi surt el nom, la sigla o el número.
- **Els períodes incomplets** (el 2026, fins al 28 d’octubre, i el darrer mandat) es dibuixen més clars. 3 lleis publicades entren en vigor després del 29 d’octubre del 2026 (branca `future`).

## Com es tornen a fer els gràfics

```sh
python visualisations/src/make.py            # git -> src/.build/ -> el-dret-andorra-en-20-grafics.html
node visualisations/src/stills.cjs           # imatges per a aquests README (cal Playwright; PLAYWRIGHT=<camí> si no és global)
```

`make.py` ho llegeix tot dels objectes de git, de manera que també funciona en un clon sense blobs (`--filter=blob:none`) o sense checkout: baixa en lots els blobs que falten de `lleis/` i `constitucio/` (uns 31.000 fitxers petits, uns 25 MB) i les taules. Per defecte llegeix `origin/main` (o `HEAD`) i `origin/future`; `--ref` i `--future` en trien d’altres. No escriu res al repositori fora de la pàgina i de la carpeta `src/.build/` (que git ignora).

| Fitxer | Què fa |
| --- | --- |
| `src/make.py` | extreu l’historial, els arbres, les taules i, de cada llei, els recomptes que fan servir els gràfics a `src/.build/`; després executa `prep.py` i `build.py` |
| `src/prep.py` | calcula tots els números dels 20 gràfics i el perfil de les dades a `src/.build/data.json` |
| `src/page.tpl.html` | la pàgina: els textos en totes dues llengües, els gràfics (d3), les taules |
| `src/build.py` | posa `data.json` a la plantilla i escriu la pàgina |
| `src/stills.cjs` | dibuixa cada gràfic com a PNG a `stills/ca/` i `stills/en/` |
