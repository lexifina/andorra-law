# Article 1
S’aprova un crèdit extraordinari per un import de 44.170,04 euros, per a les partides pressupostàries següents:
180 Secretaria d’Estat d’Esports, Joventut i Voluntariat-181 Àrea de Joventut-PROJ-0027 Desplegar Pla Nacional Joventut And-20200 Lloguer edificis i altres construccions, per un import de 25.900 euros
180 Secretaria d’Estat d’Esports, Joventut i Voluntariat-181 Àrea de Joventut-PROJ-0027 Desplegar Pla Nacional Joventut And-22620 Divulgació i publicacions, per un import de 4.775 euros
180 Secretaria d’Estat d’Esports, Joventut i Voluntariat-181 Àrea de Joventut-PROJ-0027 Desplegar Pla Nacional Joventut And-22660 Reunions, conferències i cursets, per un import de 3.200 euros
180 Secretaria d’Estat d’Esports, Joventut i Voluntariat-181 Àrea de Joventut-PROJ-0027 Desplegar Pla Nacional Joventut And-22700 Treballs realitzats per empreses de neteja i sanejament, per un import de 4.295,04 euros
180 Secretaria d’Estat d’Esports, Joventut i Voluntariat-181 Àrea de Joventut-PROJ-0027 Desplegar Pla Nacional Joventut And-48220 A institucions sense finalitat de lucre, per un import de 6.000 euros.
