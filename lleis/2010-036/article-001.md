# Article 1
S’aprova un crèdit extraordinari per un import total d’1.905.000 euros, per a les partides pressupostàries següents:
410 Departament d’Urbanisme i Ordenament Territorial-416 Àrea d’Obres Públiques. Obres-60910 Estudis i projectes d’inversió-2006-0000000011-CG2 Pont de Molleres-Canillo, per un import de 205.000 euros per a l’exercici 2010.
410 Departament d’Urbanisme i Ordenament Territorial-416 Àrea d’Obres Públiques. Obres-60700 Construcció de carreteres-2006-0000000011-CG2 Pont de Molleres-Canillo, per un import d’1.700.000 euros per a l’exercici 2011.
