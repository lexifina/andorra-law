# Article 45
Tipus de gravamen
1. Tenen la consideració de tipus de gravamen les quantitats fixes expressades en una quantitat de moneda per la base o trams de la base de tributació, així com les quantitats percentuals de caràcter proporcional o progressiu que correspongui aplicar sobre la base de tributació o base de liquidació respectiva, segons que escaigui, per determinar la quota de tributació.
2. La llei de cada tribut pot preveure l’aplicació d’un tipus zero, així com de tipus reduïts o bonificats.
