# Disposició transitòria tercera. Normativa aplicable a les armeries, els tallers de reparació d’armes, els camps i les galeries de tir, i les armes, les municions, i les parts i components d’armes
Mentre no entrin en vigor les disposicions reglamentàries a què fan referència l’apartat 1 de l’article 28 i l’apartat 2 de l’article 29, continuen sent vigents les disposicions del Decret dels veguers sobre fabricació, importació, circulació, comerç, reparació, possessió i ús d’armes, del 3 de juliol de 1989, quant a les condicions d’obertura i explotació de les armeries, els tallers de reparació d’armes, els camps i galeries de tir, i quant a la classificació de les armes i els requisits per fabricar, importar, exportar, fer circular, adquirir, comercialitzar, intermediar, cedir, reparar, tenir, emmagatzemar, vendre, usar i transportar armes, municions, i parts i components d’armes.
